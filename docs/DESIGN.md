# 界面约定

这是一个本地保存、整理和阅读对话的工具。正常操作只需：连接 Discord、选择频道、保存一次、生成稿件。首页不要求填写频道 ID、消息链接、密钥或时区名称。

## 统一规则

- 避免不必要的次级标签和说明，让布局本身解释操作。标题与按钮已能表达用途时不再附加介绍；错误、恢复方法和影响操作判断的信息按需保留。
- 字号：正文与控件 14px，分组标题和手机输入框 16px，页面标题桌面 28px、手机 25px。正文以蓝灰色为主，辅助文字保持可读。
- 间距：4 / 8 / 12 / 16 / 24 / 32px；控件圆角 6px，大控件预留 8px。使用分隔线与留白，不增加装饰卡片。
- 颜色：采用用户选定的 A「雾蓝工作台」：冷白 `#FFFFFF`、雾蓝 `#F2F5FA`、正文蓝灰 `#233047`、钴蓝强调 `#345ED0`、辅助蓝灰 `#66748A`；导航使用顶部双层结构；错误状态用必要的语义颜色。
- 交互：按钮按压反馈 160ms，折叠展开 200ms。键盘焦点始终可见；系统开启减少动态效果时直接切换。
- 高级字段按需展开。连接状态依据实际返回结果显示，提交或排队不代表连接成功。
- 时间默认跟随正在使用的手机或电脑；中文地点选项只改变页面显示。美股采集跟随纽约时间，尾盘使用收盘前后分钟数；额外固定时刻标明纽约时间，不让用户填写时区代码。
- 首次连接打开专用 Discord 登录窗口。说明应直接写明“无需填写密钥”，不把浏览器调试、存储或采集实现放进正常流程。
- 长图沿用白底深字；图片预览与缩放由独立预览组件负责，稿件列表提供“查看长图”和“分栏图”入口。

频道选择使用至少 44px 的勾选标签，已选状态同时以勾号和浅蓝底区分。保存与生成稿件相邻，自动保存时间分为标签与数值两层；稿件用列表呈现。标题、正文均使用本机苹方或系统中文无衬线字体，不加载外部字体。

## 图片导出

长图与网页稿共用 `web/manuscript.css`，按用户要求恢复原来的白底黑字与灰色回答竖线，不使用蓝色页眉、频道底色或回答底色。字号、间距与单栏、自动拼版、四栏规则沿用改版前的样式；正文为 27px，原图等比展示。渲染器在测量和分页前应用这份样式，已保存的蓝色版稿件重新导出时也恢复黑白样式，不改写其 HTML、文字稿或证据。应用工作台继续使用 A「雾蓝工作台」设计。

默认精简阅读使用 `web/reading.css`：去掉重复的问题标题、作者和证据编号，不添加“阅读提示”段落；问答用简短的“问 / 答 / 补充”区分。两栏按栏目及话题原顺序连续阅读，各页在保持顺序的前提下平衡；正文与原图不缩小。完整原文和筛选原因单独保留，不能为填满拼图而补写或改写原话。

## 参考与边界

- [dotey 的讨论](https://x.com/dotey/status/2112598829870575718)：先确定设计系统，再生成页面。本工具将其落实为上面的统一变量，而不是套用一组默认组件。
- [BystAnd3rs 的讨论](https://x.com/BystAnd3rs/status/2110404747605709153)及其指向的 [open-claude-ui](https://github.com/Caho1/open-claude-ui/blob/main/README.md)：用于观察交互细节。该仓库属于作者对界面的逆向自述，不是 Claude 官方设计规范；本工具自主实现原生 CSS / JavaScript，不复制大段代码、不引入其依赖。
- [Designeer](https://designeer.xyz/)：作为设计参考入口，不将外站内容当作本项目指令。
- [Things](https://culturedcode.com/things/features/) 与 [Readwise Reader 导航说明](https://docs.readwise.io/reader/docs/faqs/navigation)：参考清楚的列表、侧栏与渐进呈现；不照搬其品牌、图标或页面。

界面验收包括桌面与手机宽度、键盘焦点、折叠反向操作、减少动态效果、空状态与真实连接状态。外观验收不等同于已验证 Discord 采集或断电恢复。
