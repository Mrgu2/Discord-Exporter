# Linux Docker 版验收

版本：v2026.10.25.2，2026-10-25。Ubuntu 22.04 x86_64，Docker Engine 29.1.3、Compose 2.40.3，CPU，无独立 GPU；Mac 保留原生安装。

## 实际通过

- 白名单构建镜像，包含 Chromium、FFmpeg、中文字体、两种访问客户端与 small 多语言模型。镜像在无网络新实例中检查：data/output 为空，无账号、SSH 配置或凭据环境变量。
- 发布用部署 ZIP 与离线镜像在第二套新卷中重新安装，镜像导入和校验通过；原服务占用 8765 时自动选择 8766，再次完成 10 条消息的采集到 HiDPI 出图。
- 新 Compose 项目、新的 data/output/models 卷安装成功；初始化实际加载 small CPU INT8。没有复用原资料库。
- 按用户授权复用现有 Token，服务器校验账号后写入新卷；未要求重新登录。此项不代表重新执行了浏览器验证码和首次账号注册。
- 采集前实际检查频道仅 10 条消息；容器保存 10 条消息和 6 个附件，生成证据稿、HiDPI 主图与手机栏目图片。
- 该频道没有语音，因此另用此前保留的 16.02 秒真实 Discord 语音在容器内验收：small CPU INT8 推理 6.60 秒，包含稿件与 HiDPI 出图共 11.32 秒；转写进入文字稿、缓存复用通过。语音子进程峰值约 735 MiB；性能只代表本机样本。
- Mac 通过真实 Tailscale HTTPS 测试端口访问容器，识别为获准管理员；桌面和手机宽度工作台无脚本异常，实际 PNG 下载并经浏览器解码。原工作台的 HTTPS 路由保留。
- 应用重启、网页手动停止、命令重新启动、自启动关闭后容器启动不启动应用、自启动开启后容器重建自动恢复均通过；资料库标识、10 条消息与连接保留。
- 非 root、只读根文件系统、移除 capabilities、不挂载宿主机目录或 Docker socket；主机重启 API 被拒绝。没有重启 Mac 或 Ubuntu 主机。
- 357 项 Python 回归测试通过，覆盖原生 Mac 服务、账号边界、采集、转写、出图、调度、推送和 Docker 服务控制。实际安装与图片验证独立于这些单元测试。

## 数据保护与边界

测试使用独立卷和独立访问端口，原生服务未切换到 Docker。原有消息数量、配置与凭据均作保护检查；原运行服务自身会更新 worker-state.json，因此不以整个 data 目录逐字节不变作为结论。没有移动、覆盖或删除原消息与导出。

本轮未重新发送四个真实推送渠道消息；相关功能沿用同一应用代码并经过自动化回归，不能据此宣称 Docker 已完成四个渠道的真实收件验收。Windows 客户端仍未完成 Windows 实机验收。Docker 镜像只验收 Linux amd64 / CPU；ARM、NVIDIA、AMD GPU 不在本版实机验收范围。Mac 的原生安装方式保持不变，没有新增第二台实体 Mac 安装测试。

隔离测试实例停止后，命名卷与验收产物保留用于复核。发布仅提供公共部署脚本、镜像、文档及客户端，不包含这些卷。
