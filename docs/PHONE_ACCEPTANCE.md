# 移动端验证方法

本页说明验证方法；实测结论以对应版本验收记录为准。样例与日志不得包含私人账号、凭据或聊天。

在实际设备上验证配对、刷新后的会话、日期选择、保存、出稿、长图缩放和平移、Markdown 与 PNG 下载。分别检查浏览器快速预览和独立图片查看器；两者结果不能相互替代。

模拟屏宽检查：

```sh
node tests/ui_check.mjs
node tests/workflow_ux_check.mjs
```

PNG 兼容性检查应覆盖 CRC、完整解码和 sRGB 标签。模拟浏览器不证明所有手机系统或超大图查看器兼容。测试记录不应公开设备型号、账号、实际稿件链接、系统日志或截图元数据。
