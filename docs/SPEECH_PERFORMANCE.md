# 本地语音与性能验证

本页说明验证方法；实测结论以对应版本验收记录为准。样例与日志不得包含私人账号、凭据或聊天。

语音先留存再离线转写，转写作为派生记录，不覆盖原消息。缓存包含音频哈希、模型和推理配置；模型按批次加载。失败保留待转写状态，不将已经留存的消息判为丢失。

```sh
python3 -m unittest discover -s tests -p 'test_speech.py'
python3 scripts/benchmark_history.py --messages-per-channel 120 --rounds 8
```

性能比较使用同一份公开或合成输入，分别记录冷启动、缓存命中和渲染，不把单次样例推广为通用速度。准确率必须基于人工标注集；金融术语、数字及同音词仍需回听。不得把私人语音或转写片段加入测试。
